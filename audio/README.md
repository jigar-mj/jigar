# Voice Samples Folder

Upload your voice sample MP3 files here so that **all visitors can listen** to them
directly on the website (free, served by GitHub Pages).

## How to name files

Name each file using the **lowercase language name**, with spaces and symbols
replaced by hyphens, ending in `.mp3`.

| Language          | File name to upload         |
|-------------------|-----------------------------|
| Rohingya          | `rohingya.mp3`              |
| Burmese           | `burmese.mp3`               |
| Wolof             | `wolof.mp3`                 |
| Pashto            | `pashto.mp3`                |
| Gujarati          | `gujarati.mp3`              |
| Hindi             | `hindi.mp3`                 |
| Persian (Farsi)   | `persian-farsi.mp3`         |
| Greek             | `greek.mp3`                 |

## What happens automatically

- If a file like `audio/rohingya.mp3` exists, the Rohingya card on the site
  will show a working audio player for everyone.
- If no file exists for a language, the card shows
  "Voice sample available on request."

## Tip

Convert WAV to MP3 first (smaller, faster to load) using a free tool like
[convertio.co](https://convertio.co). Keep samples short (30-60 seconds).
