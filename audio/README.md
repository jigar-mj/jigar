# Voice Samples Folder

Upload your voice sample MP3 files here so that **all visitors can listen** to them
directly on the website (free, served by GitHub Pages).

## One speaker per language

Name the file using the **lowercase language name**, spaces/symbols replaced by
hyphens, ending in `.mp3`.

| Language          | File name to upload         |
|-------------------|-----------------------------|
| Rohingya          | `rohingya.mp3`              |
| Burmese           | `burmese.mp3`               |
| Wolof             | `wolof.mp3`                 |
| Pashto            | `pashto.mp3`                |
| Gujarati          | `gujarati.mp3`              |
| Persian (Farsi)   | `persian-farsi.mp3`         |

## Multiple speakers for the same language

Add a number at the end: `-1`, `-2`, `-3` ... (up to `-8`).

| Speaker            | File name to upload   |
|--------------------|-----------------------|
| Gujarati speaker 1 | `gujarati-1.mp3`      |
| Gujarati speaker 2 | `gujarati-2.mp3`      |
| Gujarati speaker 3 | `gujarati-3.mp3`      |

The website will automatically show a separate player labelled
**Speaker 1, Speaker 2, ...** for every file it finds.

## What happens automatically

- If a matching file exists, the language card shows a working audio player
  for everyone.
- If no file exists, the card shows "Voice sample available on request."

## Tip

Convert WAV to MP3 first (smaller, faster) using a free tool like
[convertio.co](https://convertio.co). Keep samples short (30-60 seconds).
