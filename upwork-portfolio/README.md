## Convert SVG → PNG (for Upwork)

Upwork portfolio accepts PNG/JPG. Convert each SVG using one of these:

1. **CloudConvert** (free, fast): https://cloudconvert.com/svg-to-png
2. **Canva**: Upload SVG → Download as PNG
3. **Chrome screenshot**: Open SVG → DevTools (F12) → Cmd+Shift+P → "Capture full size screenshot"

**Recommended PNG export size:** 1920×1080 (or 2560×1440 for retina sharpness)

- **Accent:** Gold (#F5C857 → #D49B2E) — Saturn/Jupiter alignment
